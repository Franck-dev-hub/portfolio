# Portfolio Franck S.

Personal portfolio, styled like a tiling window manager desktop.

#### [Live demo](https://franck-dev-hub.github.io/portfolio/)

## Features

- English and French, follows the browser language, switchable in the header.
- Light and dark themes, follows the browser preference, dark by default.
- Contact form.
- No cookies, no tracking. The language and theme choices stay in `localStorage`.
